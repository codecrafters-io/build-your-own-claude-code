# Supplied LSP clients

Current starter repositories include the client for your language. Follow Stage 1
in CodeCrafters to import and initialize it.

## Troubleshooting older repositories

If you started the course before the client was included, your repository may be
missing it. Download the entire client file for your language below and save it
at the shown path. If your repository has an older client that does not match the
lesson's API, replace that client file with the current version.

| Language | Client file | Save to |
| --- | --- | --- |
| C | [lsp_client.h](../starter_templates/c/code/src/lsp_client.h) | `src/lsp_client.h` |
| C++ | [lsp_client.hpp](../starter_templates/cpp/code/src/lsp_client.hpp) | `src/lsp_client.hpp` |
| C# | [LSPClient.cs](../starter_templates/csharp/code/src/LSPClient.cs) | `src/LSPClient.cs` |
| Go | [lsp_client.go](../starter_templates/go/code/app/lsp_client.go) | `app/lsp_client.go` |
| Java | [LSPClient.java](../starter_templates/java/code/src/main/java/LSPClient.java) | `src/main/java/LSPClient.java` |
| JavaScript | [lsp_client.js](../starter_templates/javascript/code/app/lsp_client.js) | `app/lsp_client.js` |
| Python | [lsp_client.py](../starter_templates/python/code/app/lsp_client.py) | `app/lsp_client.py` |
| Rust | [lsp_client.rs](../starter_templates/rust/code/src/lsp_client.rs) | `src/lsp_client.rs` |
| TypeScript | [lsp_client.ts](../starter_templates/typescript/code/app/lsp_client.ts) | `app/lsp_client.ts` |
| Zig | [lsp_client.zig](../starter_templates/zig/code/src/lsp_client.zig) | `src/lsp_client.zig` |

Optional local-server and protocol details are in the
[advanced guide](advanced_usage.md).
